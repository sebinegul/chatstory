# ChatStory

Turn a WhatsApp chat export into a printable storybook PDF. Upload your chat, walk through a short flow, pay a mock Rs.49 fee, and generate a storybook.

Built with Next.js. OpenRouter-ready for AI story generation.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Copy the example env file and fill in values as needed (no real keys required for local mock pay):

```bash
copy .env.example .env
```

3. Start the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
